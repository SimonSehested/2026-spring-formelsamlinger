\section{Feed-forward control}

\subsection{Ctrl+F keywords}

\subsubsection{Feed-forward, feedforward, disturbance cancellation, forstyrrelseskompensering}
\[
\text{measured disturbance, dynamic feed-forward, static feed-forward, properness, }F_d(s)
\]
Use this section when the disturbance is measured and the problem asks for cancellation before feedback reacts.

\subsection{Feed-forward principle}

\subsubsection{Feedback plus feed-forward input}
\[
u(t)=u_{\mathrm{fb}}(t)+u_{\mathrm{ff}}(t)
\]
Feed-forward acts directly from reference or measured disturbance and does not need an error first.

\subsubsection{Disturbance path model}
\[
Y(s)=G(s)U(s)+D(s)d(s)
\]
\(G\) is the manipulated-input path and \(D\) is the disturbance path.

\subsection{Dynamic disturbance feed-forward}

\subsubsection{Ideal disturbance cancellation with diagram sign}
\[
\begin{array}{c|c}
\text{Disturbance contribution} & \text{Ideal feed-forward}\\ \hline
D(s)d(s)+G(s)F_d(s)d(s) & F_d(s)=-D(s)/G(s)\\
-D(s)d(s)+G(s)F_d(s)d(s) & F_d(s)=D(s)/G(s)
\end{array}
\]
Choose the sign from the summing junction in the block diagram. The nominal disturbance contribution must become zero.

\subsubsection{Disturbance sensitivity with feed-forward}
\[
G_{yd}(s)=\frac{\sigma_DD(s)+G(s)F_d(s)}{1+C(s)G(s)},\qquad \sigma_D\in\{-1,+1\}
\]
The sign \(\sigma_D\) is read from the disturbance summing junction. Feedback divides the remaining model mismatch by \(1+CG\).

\subsubsection{Static feed-forward}
\[
F_d(0)=-\frac{\sigma_DD(0)}{G(0)}
\]
Static feed-forward cancels constant disturbances when the relevant DC gains exist.

\subsubsection{Properness condition}
\[
\deg D(s)-\deg G(s)\leq0
\]
The ideal \(F_d=-\sigma_DD/G\) must be proper and stable; otherwise add a realizable filter.

\subsubsection{Filtered feed-forward}
\[
F_{d,\mathrm{filt}}(s)=-\frac{\sigma_DD(s)}{G(s)}Q(s)
\]
\(Q(s)\) is typically a low-pass filter used to make the feed-forward realizable or less noise-sensitive.

\subsection{Exam recipe: design dynamic disturbance feed-forward}

\textbf{Use when:} the task gives \(G(s)\), \(D(s)\), and asks for a feed-forward block.

\textbf{Steps:}
\begin{enumerate}
\item Read the sign of the disturbance path from the summing junction.
\item Write the output contribution \(Y_d=G U_{\mathrm{ff}}+\sigma_DD d\).
\item Set \(U_{\mathrm{ff}}=F_d d\).
\item Solve \(G F_d+\sigma_DD=0\) to get \(F_d=-\sigma_DD/G\).
\item Check that \(F_d\) is stable and proper.
\item If not proper or too aggressive, multiply by a low-pass \(Q(s)\).
\end{enumerate}

\textbf{Fast checks:} the sign must oppose the disturbance path; \(\sigma_DD+GF_d=0\) for the ideal model.

\textbf{Common traps:} cancelling with the wrong plant path; ignoring improper differentiation in \(F_d\).

\subsection{Exam recipe: feed-forward versus feedback}

\textbf{Use when:} answer options compare disturbance rejection methods.

\textbf{Steps:}
\begin{enumerate}
\item Feed-forward needs a measured disturbance or known reference.
\item Feedback works on unmeasured disturbances but only after error appears.
\item Feed-forward depends strongly on model accuracy.
\item Feedback still determines closed-loop stability margins.
\end{enumerate}

\textbf{Fast checks:} adding feed-forward outside the feedback loop does not by itself change \(1+C(s)G(s)\).
