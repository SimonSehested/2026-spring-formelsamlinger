\section{Course overview and control concepts}

\subsection{Linear Control Design 1}

\subsubsection{PID-based controller structure}
\[
C_{\mathrm{PID}}(s)=K_P\left(1+\frac{1}{\tau_i s}+\tau_d s\right)
\]
The course focuses on PID-based controller design for linear models. The parameters \(K_P\), \(\tau_i\), and \(\tau_d\) set proportional action, integral action, and derivative action.

\subsubsection{Feedback control objective}
\[
e(t)=r(t)-y_m(t), \qquad u(t)=C(s)e(t)
\]
The controller acts on the error between the reference and the measured output. Feedback is used to shape tracking, disturbance rejection, stability margins, and robustness.

\subsubsection{Control performance keywords}
\[
\{t_r,\ t_s,\ M_p,\ e_{\mathrm{ss}},\ \omega_c,\ \gamma_M,\ A_M\}
\]
The recurring specifications are rise time, settling time, overshoot, steady-state error, crossover frequency, phase margin, and gain margin.
