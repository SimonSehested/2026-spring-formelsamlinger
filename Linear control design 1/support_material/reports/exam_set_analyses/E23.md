## Opgave-for-opgave analyse

### Q1
**Kort beskrivelse:** Find open-loop transfer for blokdiagram med `C1`, `C2`, `G`, `H`; facit `Gopen=C1(1+C2)GH`.  
**Genkendelsessignaler:** Blokdiagram med controllerdel før plant og sensorfeedback.  
**Relevant pensum:** Blokdiagramreduktion.  
**Hurtig løsning:** Find forward path omkring loopet: controllerens effekt er `C1` multipliceret med parallel/indre bidrag `1+C2`, derefter `G` og sensor `H` i loopproduktet.  
**Centrale formler:** Loop transfer er produktet omkring feedbacksløjfen.  
**Symboler/input:** `C1,C2,G,H`.  
**Antagelser:** Negativ feedback og lineære blokke.  
**Typiske fælder:** At bruge `C1+C2` i stedet for `C1(1+C2)`.  
**Hurtigtjek:** Hvis `C2=0`, skal loopet blive `C1GH`.  
**Python-vurdering:** `notes_only`.

### Q2
**Kort beskrivelse:** Find closed-loop transfer `Gcl=Y/R`; facit `C1(1+C2)G/[1+C1(1+C2)GH]`.  
**Genkendelsessignaler:** Samme blokdiagram som Q1, men uden sensor `H` i forward numerator.  
**Relevant pensum:** Closed-loop transfer.  
**Hurtig løsning:** Numerator er forward path fra reference til output; denominator er `1+loop`.  
**Centrale formler:** `Gcl=forward/(1+loop)`.  
**Typiske fælder:** At inkludere `H` i numerator fra `R` til `Y`.  
**Hurtigtjek:** Sensoren ligger i feedback path, ikke output path.  
**Python-vurdering:** `notes_only`.

### Q3
**Kort beskrivelse:** Med `C1=K1`, `C2=K2/s`, `G=k/(tau s+1)`, `H=1/(tau_h s+1)`, find type og orden for open-loop; facit type 1, order 3.  
**Genkendelsessignaler:** Integrator i controller og to førsteordensblokke.  
**Relevant pensum:** Systemtype og orden.  
**Hurtig løsning:** `1+C2=(s+K2)/s` giver én integrator i nævneren; sammen med `G` og `H` fås tre poler samlet.  
**Centrale formler:** Type = antal origo-poler i open-loop; order = nævnergrad efter forkortning.  
**Typiske fælder:** At tælle `1+C2` som type 0 uden at samle brøken.  
**Hurtigtjek:** `1+K2/s=(s+K2)/s` har stadig integrator.  
**Python-vurdering:** `notes_only`.

### Q4
**Kort beskrivelse:** Find static loop-gain `K0`; facit `K0=K1*K2*k`.  
**Genkendelsessignaler:** Type-1 loop og static velocity-like gain.  
**Relevant pensum:** Statisk loopgain og systemtype.  
**Hurtig løsning:** For type 1 beregnes `K0=lim_{s->0} s Gopen(s)`. Indsæt `C1(1+C2)GH`; kun `K2/s`-delen overlever i produktet med `s`, og `H(0)=1`.  
**Centrale formler:** `K0=lim s^n L(s)` for type `n`.  
**Typiske fælder:** At bruge `1+K2` eller dividere med tidskonstanter ved DC-normaliserede blokke.  
**Hurtigtjek:** Tidskonstantblokke har DC-gain 1.  
**Python-vurdering:** `notes_only`.

### Q5

**Genkendelsessignaler:** P-led plus integralled i parallel/serieform.

**Hurtig løsning:** `C1(1+C2)=K1(1+K2/s)` indeholder proportionaldel og integrator.  
**Centrale formler:** PI-form `Kp(1+1/(Ti s))`.  
**Typiske fælder:** At kalde den P-Lead fordi der er et zero; PI-zero kommer sammen med integrator.  
**Hurtigtjek:** Integrator i controlleren hæver systemtypen.  
**Python-vurdering:** `notes_only`.

### Q6
**Kort beskrivelse:** State model `x1dot=x2`, `x2dot=-a x1-b x2+c u`, `y=x1`; facit type 0, order 2.  
**Genkendelsessignaler:** Andenordens state-space uden integrator i input-output TF.  
**Relevant pensum:** State-space til transferfunktion.  
**Hurtig løsning:** To states giver orden 2; transferfunktionen har nævner `s^2+bs+a` og ingen origo-pol hvis `a>0`.  
**Centrale formler:** `G(s)=C(sI-A)^{-1}B+D`.  
**Typiske fælder:** At tælle `x1dot=x2` som en fri integrator i input-output type.  
**Hurtigtjek:** Hvis `a>0`, `G(0)=c/a` endelig.  
**Python-vurdering:** `notes_only`.

### Q7
**Kort beskrivelse:** Find `G(s)` fra samme state equations; facit `c/(s^2+bs+a)`.  
**Genkendelsessignaler:** Output `y=x1` og input i anden ligning.  
**Relevant pensum:** Laplace/state-space.  
**Hurtig løsning:** Laplace: `sX1=X2`, `sX2=-aX1-bX2+cU`; indsæt `X2=sX1` og isoler `X1/U`.  
**Centrale formler:** `G=c/(s^2+bs+a)`.  
**Typiske fælder:** At placere `a` foran `s^2`.  
**Hurtigtjek:** DC-gain er `c/a`.  
**Python-vurdering:** `script_assisted`.
