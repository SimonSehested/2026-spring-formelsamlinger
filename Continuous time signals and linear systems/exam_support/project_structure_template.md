# Project Structure Template

This file is optional. It gives a clean starting structure for future courses.

```text
course_project/
  AGENTS.md
  PLAN.md
  style_guide.md
  script_guide.md
  verification_guide.md
  script_verification_guide.md
  README_PROMPT.md

  input/
    exams/
    solutions/
    lectures/
    slides/
    exercises/

  sources/ or sections/
    01_inferred_topic.tex
    02_inferred_topic.tex

  scripts/
    __init__.py
    inferred_topic/
      __init__.py
      task_functions.py
    validate_scripts.py

  examples/
    exam_toolbox_demo.py

  reports/
    coverage_report.md
    exam_task_taxonomy.md
    script_inventory.md
    script_verification_report.md
    exam_verification_report.md

  main.tex
  requirements.txt
```

Do not force this exact structure if the repository already has a useful structure. Preserve and improve existing structure when possible.
