\section*{Trees, ensembles, ANN}
\subsection*{Decision tree split}
\[
\fid[eq:tree-imp]\begin{aligned}
I_{\rm error}&=1-\max_cp_c,&
I_{\rm Gini}&=1-\sum_cp_c^2,\\
I_{\rm ent}&=-\sum_cp_c\log_2p_c,&
\operatorname{gain}&=I(\text{parent})-\sum_v\frac{N_v}{N}I(\text{child }v).
\end{aligned}
\]
\textbf{Do this:} for each candidate split, count class labels in every node; compute $p_c=n_c/N_{\rm node}$; insert $p_c$ in the chosen impurity in \fref{eq:tree-imp}; multiply each child impurity by $N_v/N$; choose the split with largest gain. Read a tree by following thresholds from root to leaf; classification leaf returns majority/class fractions, regression leaf returns mean response.
\textbf{Regression tree:} replace class fractions by response variance/SSE inside each node if the task is numeric prediction; the chosen split is the one giving the lowest weighted child error or largest error reduction.

\subsection*{AdaBoost}
\[
\fid[eq:adaboost]\begin{aligned}
\epsilon_t&=\sum_iq_i^{(t)}\ind[h_t(x_i)\ne y_i],&
\alpha_t&=\frac12\log\frac{1-\epsilon_t}{\epsilon_t},\\
q_i^{(t+1)}&\propto q_i^{(t)}
\exp\!\big(\alpha_t\ind[h_t(x_i)\ne y_i]\big),&
H(x)&=\operatorname{sign}\sum_t\alpha_th_t(x).
\end{aligned}
\]
\textbf{Do this:} use signed labels/classes for $h_t$. In \fref{eq:adaboost}, add current weights $q_i^{(t)}$ only for misclassified rows to get $\epsilon_t$; compute $\alpha_t$; multiply each row weight by the shown factor; divide all new weights by their sum so they add to $1$; final class is the sign of weighted votes.

\subsection*{Neural-network forward pass}
\[
\fid[eq:ann]\begin{aligned}
a_j&=w_{0j}^{(1)}+\sum_mw_{mj}^{(1)}x_m,\\
h_j&=g(a_j),\\
\hat y&=w_0^{(2)}+\sum_jw_j^{(2)}h_j,\\
\operatorname{ReLU}(a)&=\max(0,a),\quad
\sigma(a)=\frac1{1+e^{-a}},\quad
\tanh(a)\in[-1,1].
\end{aligned}
\]
\textbf{Do this:} from a diagram/table, gather all incoming weights for hidden unit $j$; compute $a_j$ with \fref{eq:ann}; apply the stated activation to get $h_j$; multiply hidden outputs by outgoing weights and add output bias; apply final sigmoid/threshold only if the task says classification probability/class.
\textbf{Reading weights:} a large positive incoming weight makes that input increase the hidden activation; a large negative weight makes it decrease. Bias is added even when all inputs are zero.
